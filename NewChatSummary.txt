PROJECT: cazzyjobs - Current Status & Roadmap Summary
*(Last Updated: 2025-09-12)*

🎯 Core Concept
A privacy-focused recruitment platform connecting local casual workers with employers. Address sharing only after hire. No financial transactions - pure connection platform.

🏗️ Tech Stack & Environment
Framework: Expo SDK 53 (Managed Workflow)
Frontend: React Native 0.79.6, React 18.2.0
Navigation: React Navigation v7 (Native Stack + Bottom Tabs)
Backend: Supabase (Auth, Database, Storage, Realtime)
Storage: Supabase Storage bucket 'profile_pic' with public access
Current Branch: feat/profile-enhancements

📊 Database Schema Extraction Commands
sql
-- Get table structure
SELECT table_name, column_name, data_type, is_nullable, column_default
FROM information_schema.columns 
WHERE table_schema = 'public' AND table_name IN ('profiles', 'jobs', 'applications', 'messages', 'notifications')
ORDER BY table_name, ordinal_position;

-- Get RLS policies
SELECT tablename, policyname, permissive, roles, cmd, qual, with_check
FROM pg_policies 
WHERE schemaname = 'public' AND tablename IN ('profiles', 'jobs', 'applications', 'messages', 'notifications')
ORDER BY tablename, policyname;

-- Get storage policies
SELECT * FROM storage.buckets WHERE name = 'profile_pic';
SELECT * FROM storage.policies WHERE bucket_id = 'profile_pic';

Role-Based Navigation: Tabs hide/show based on user role
