CAZZYJOBS - Project Summary & Status Report
🎯 App Purpose & Target Audience
Core Mission: Privacy-focused platform connecting local casual workers with employers for offline financial arrangements.

Target Users:

Workers: Lower-income, less educated unemployed individuals seeking casual work (gardening, cleaning, moving, etc.)

Employers: Small businesses, homeowners, community members needing temporary help

Key Differentiator: No contact details exposed pre-hire, address sharing only after connection. No payment processing - pure connection platform.

🏗️ Technical Stack
Framework: Expo SDK 53 (Managed Workflow)

Frontend: React Native 0.79.6, React 18.2.0

Navigation: React Navigation v7 (Native Stack + Bottom Tabs)

Backend: Supabase (Auth, Database, Storage, Realtime)

Storage: Supabase Storage bucket 'profile_pic'

📊 Supabase Schema Highlights
Tables:

profiles: Role-based users (worker/employer) with location, phone, terms acceptance

jobs: Job postings with status management (active/completed/cancelled)

applications: Application tracking (pending/hired/rejected/completed)

messages: Real-time chat for hired connections

notifications: Alert system

Key Constraints:

sql
jobs.status = ANY (ARRAY['active','completed','cancelled'])
applications.status = ANY (ARRAY['pending','hired','rejected','completed'])
profiles.user_role = ANY (ARRAY['worker','employer'])
